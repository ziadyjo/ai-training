# Sesi 1: Review-Ready BRDs with Claude

Tiga hands-on: membangun Skill `brd-draft`, memeriksa BRD hasilnya dengan `brd-review`, lalu menyusun BRD terstandar dari notulen meeting.

Setiap folder hands-on berisi langkah-langkahnya dan folder `sources/` dengan berkas yang dipakai di hands-on itu.

| Folder | Isi |
|---|---|
| [`hands-on-1/`](hands-on-1/) | Build Requirement Review & BRD Skill. Langkah 00 sampai 05, prompt siap salin, dan `sources/` |
| [`hands-on-2/`](hands-on-2/) | Requirement Gap Analysis. Langkah 01 sampai 04, prompt siap salin, dan `sources/` |
| [`hands-on-3/`](hands-on-3/) | Standardized BRD & Skill Refinement. Langkah 01 sampai 05, prompt siap salin, dan `sources/` |
| `scorecard.md` di [`hands-on-2/`](hands-on-2/scorecard.md) dan [`hands-on-3/`](hands-on-3/scorecard.md) | Tabel untuk mencatat Skor mutu: review BRD v1.0 (Hands-on #2) dan versi BRD bersambung (Hands-on #3). Hands-on #1 tidak memakainya |
| [`glossary.md`](glossary.md) | Istilah yang dipakai di Sesi 1 |

**Alur BRD di Sesi 1.** Template disalin menjadi BRD v1.0 (Hands-on #1), direview (Hands-on #2), lalu v1.0 disalin menjadi v1.1 dan diperbarui dengan notulen, v1.1 menjadi v1.2 setelah Skill diperbaiki (Hands-on #3). Tiap versi adalah salinan versi sebelumnya, bukan dibuat dari template kosong. Cakupan BRD dibatasi ke kelompok fitur **Role Management**, karena Sesi 2 sampai 4 hanya memakai modul itu dan supaya penulisan ke Google Docs selesai dalam beberapa menit. Versi terakhir menjadi dasar Sesi 2.

Template BRD tidak ada di repository ini. Buka [Template BRD](https://docs.google.com/document/d/1mQB_06ReQ9WnhM4of3NWRyncfTr00yO1io7RMf4wp_8/edit?usp=sharing) (hanya baca), lalu klik **File > Make a copy** untuk membuat salinanmu sendiri di Google Docs. Connector membaca dan menulis lewat salinan di Drive-mu, bukan template asli.
