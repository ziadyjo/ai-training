# Langkah 1: Siapkan v1.1, notulen, dan gap list

Durasi ±5 menit. Langkah ini persiapan saja, belum ada prompt. Notulen meeting dan gap list dilampirkan di chat yang akan dipakai sampai Langkah 5, dan salinan BRD v1.1 disiapkan.

## Yang dikerjakan

1. Buka `BRD WebTM v1.0` (hasil Hands-on #1), klik **File > Make a copy**, beri nama `BRD WebTM v1.1`, lalu salin link salinan itu. Jangan menulis di dokumen v1.0: ia tetap menjadi titik awal.
2. Buka chat baru di dalam Project dan pilih **Opus 5.5**. Pakai chat ini sampai Langkah 5 selesai.
3. Lampirkan notulen meeting klarifikasi ([`sources/meeting-notes.pdf`](sources/meeting-notes.pdf)) lewat tombol **+**. Notulen bertanggal Selasa, 20 Oktober 2026, 10.00–11.00.
4. Salin gap list dari Hands-on #2: klik tombol salin di jawaban akhir Langkah 4 chat Hands-on #2, lalu tempel di pesan chat ini tanpa mengirimnya. Lanjut ke Langkah 2 dan kirim bersama prompt.

## Cek

- Salinan `BRD WebTM v1.1` ada, dan `BRD WebTM v1.0` tidak berubah.
- Notulen terlampir dan gap list sudah tertempel di kotak pesan.

Tertinggal atau gap list Hands-on #2 tidak ada? Pakai gap list acuan [`../hands-on-2/sources/gap-list-checkpoint.md`](../hands-on-2/sources/gap-list-checkpoint.md).
