# CLAUDE.md (template)

Salin, lalu sesuaikan dengan folder dan BRD-mu. Targetnya satu layar.

```
# Prototype WebTM: Create New Role

## Tujuan
Prototype HTML yang bisa diklik untuk alur Create New Role di WebTM (admin web, pengguna Super Admin). Untuk demo dan diskusi, bukan kode produksi.

## Struktur
- Satu berkas index.html (HTML, CSS, JavaScript di dalamnya). Tanpa framework, tanpa server.
- references/ berisi BRD, brief UI, dan mockup. Jangan diubah.
- NOTES.md berisi hal yang belum diputuskan BRD.

## Sumber kebenaran
BRD lebih tinggi dari brief UI, brief UI lebih tinggi dari mockup. Bila bertentangan, ikuti BRD dan catat di NOTES.md.

## Aturan
- Beri komentar HTML dengan ID requirement di tiap blok (mis. <!-- RM-004 -->).
- Hal yang belum diputuskan BRD ditulis TBC di layar dan dicatat di NOTES.md.
- Jangan menambah fitur di luar BRD. Tidak ada login dan tidak ada hapus role.
- Data contoh fiktif. Jangan memakai nama atau email asli.
- Tampilkan rencana dan tunggu persetujuan sebelum mengubah berkas.
- Setelah mengubah, jelaskan dalam tiga kalimat apa yang berubah.
```
