# Langkah 5: Simpan hasil dan tautkan ke BRD

Durasi ±10 menit. Mockup yang tidak tertaut ke BRD akan sulit dicari di Sesi 3, saat prototype dibuat dari desain ini.

## Yang dikerjakan

1. Buka project di Stitch (web). Kalau memakai Claude Design, ikuti bagian C3 di [claude-design.md](claude-design.md). Cari menu ekspor dan lihat opsi yang tersedia di akunmu (opsi bisa berbeda per akun). Simpan semua screen dalam satu format yang tersedia, misalnya PDF atau gambar. Kalau tidak ada opsi ekspor, ambil screenshot tiap screen.
2. Namai berkas dengan nama screen dan ID requirement, misalnya `create-new-role-RM-004.png`.
3. Buka BRD-mu. Di bagian 7 (Requirement), isi kolom atau baris **User Interface** untuk requirement Create New Role dengan link project Stitch (atau link desain Claude Design). Tulis link sebagai hyperlink.
4. Tempel satu gambar screen utama (Create New Role) di bagian 7 atau Appendix, dengan satu kalimat keterangan.
5. Salin tabel brief dari Langkah 2 ke catatanmu. Sesi 3 memakainya sebagai referensi prototype.
6. Reviewer mengecek bahwa isi BRD selain bagian User Interface tidak berubah (Version history di Google Docs).

Langkah ini manual. `ui-brief` tidak menulis ke Google Docs.

## Cek

- Link Stitch dan minimal satu gambar screen ada di BRD.
- Nama berkas screen memuat ID requirement.
- Tabel brief tersimpan untuk Sesi 3.
- [Scorecard](../scorecard.md) v1 dan v2 untuk UI terisi.
