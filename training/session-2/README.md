# Sesi 2: Process Flows & UI Mockups

Dua hands-on: mengubah BRD hasil Sesi 1 menjadi process flow di Miro (lewat connector) dengan `/flow-diagram`, lalu menjadi 3 sampai 4 screen UI di Google Stitch (lewat MCP) dengan `/ui-brief`. Claude Design menjadi alternatif bila Stitch tidak terhubung. Di antaranya kamu mengenal Connector dan MCP.

Setiap folder hands-on berisi langkah-langkahnya dan folder `sources/` dengan berkas yang dipakai di hands-on itu.

| Folder | Isi |
|---|---|
| [`hands-on-1/`](hands-on-1/) | Requirement-to-Process Flow. Quick Setup Miro, langkah 1 sampai 5, prompt siap salin, dan `sources/` |
| [`hands-on-2/`](hands-on-2/) | Requirement-to-UI Design Exploration. Langkah 1 sampai 5, prompt siap salin, dan `sources/` |
| [`scorecard.md`](scorecard.md) | Tabel untuk membandingkan hasil antar versi di tiap hands-on |

## Yang perlu siap

- BRD hasil Sesi 1 di Google Docs (versi terakhir dari Hands-on #3 Sesi 1, v1.2 atau lebih baru), atau [`BRD acuan`](../session-1/hands-on-3/sources/brd-v1-1-checkpoint.md) bila tertinggal.
- Project **WebTM Role & User Management** dari Sesi 1, dengan connector Google Docs yang masih Connected.
- Referensi tambahan (opsional): [`Reference BRD Role Management`](reference-brd-role-management.md), potongan BRD asli untuk mengecek detail layar dan skenario. BRD utamamu tetap hasil Sesi 1.
- Akun Miro (paket free didukung connector) dan akun Google untuk Stitch.
- Claude Code terpasang di laptopmu (cek `claude --version` di terminal). Dipakai di Hands-on #2 untuk menghubungkan Stitch lewat MCP. Panduan: [instalasi Claude Code](https://code.claude.com/docs/en/setup).

Skill `flow-diagram` dan `ui-brief` tidak ada di Claude-mu. Kamu memasangnya di langkah 1 tiap hands-on dari berkas di folder `sources/`.
