# CLAUDE.md (template)

Salin, lalu sesuaikan dengan folder dan BRD-mu. Targetnya satu layar.

```
# Prototype WebTM: Role Management

## Tujuan
Prototype HTML yang bisa diklik untuk Role Management WebTM (admin web, pengguna Super Admin). Untuk demo, diskusi, dan pengujian di Sesi 4. Bukan kode produksi.

## Struktur
- Satu berkas index.html (HTML, CSS, JavaScript di dalamnya). Tanpa framework, tanpa server.
- references/ berisi BRD v1.1 dan desain Claude Design. Jangan diubah.
- PLAN.md berisi rencana yang disetujui. NOTES.md berisi hal yang belum diputuskan BRD.

## Sumber kebenaran
BRD untuk perilaku (aturan, validasi, data). Desain Claude Design untuk tampilan (layout, warna, label). Bila bertentangan, ikuti BRD dan catat di NOTES.md.

## Aturan
- Beri komentar HTML dengan ID requirement di tiap blok (mis. <!-- RM-004 -->).
- Hal yang belum diputuskan BRD ditulis TBC di layar dan dicatat di NOTES.md.
- Setiap tombol dan field punya teks label yang terlihat dan atribut id yang jelas (untuk pengujian Sesi 4).
- Data contoh fiktif. Jangan memakai logo, nama, atau email asli.
- Tampilkan rencana dan tunggu persetujuan sebelum mengubah berkas.
- Setelah mengubah, jelaskan dalam tiga kalimat apa yang berubah.

## Larangan
- Jangan menambah fitur di luar BRD. Tidak ada login dan tidak ada hapus role.
- Jangan menyalin kode ekspor Claude Design. Pakai hanya sebagai acuan tampilan.
```
