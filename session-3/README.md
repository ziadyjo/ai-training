# Sesi 3: HTML Prototypes & Project Tracking

Tiga hands-on: membangun prototype HTML dari desain Claude Design dan BRD dengan Claude Code di tab Code, menyusun backlog di Notion dari requirement, lalu membuat scheduled task yang membaca backlog dan MoM di Notion untuk brief progres. Memakai BRD v1.1, flow Miro, dan desain Claude Design dari Sesi 1 dan 2.

Setiap folder hands-on berisi langkah-langkahnya dan folder `sources/` dengan berkas yang dipakai di hands-on itu.
