# Sesi 3: HTML Prototypes & Project Tracking

Tiga hands-on: membangun prototype HTML dari mockup dan BRD dengan Claude Code, menyusun backlog di Notion dari requirement, lalu membuat brief progres terjadwal dari backlog itu. Memakai BRD, flow, dan mockup dari Sesi 1 dan 2.

Setiap folder hands-on berisi langkah-langkahnya dan folder `sources/` dengan berkas yang dipakai di hands-on itu.

| Folder | Isi |
|---|---|
| [`hands-on-1/`](hands-on-1/) | Design-to-Code Development (90 menit). Langkah 1 sampai 6, prompt siap salin, `sources/` |
| [`hands-on-2/`](hands-on-2/) | Project Planning & Backlog Development (30 menit). Langkah 1 sampai 4, prompt siap salin, `sources/` |
| [`hands-on-3/`](hands-on-3/) | Scheduled Project Progress Brief (30 menit). Langkah 1 sampai 4, prompt siap salin, `sources/` |
| [`scorecard.md`](scorecard.md) | Tabel untuk membandingkan hasil antar versi di tiap hands-on |
| [`glossary.md`](glossary.md) | Istilah yang dipakai di Sesi 3 |

## Yang perlu siap

- BRD hasil Sesi 1 di Google Docs, dengan tautan flow (bagian 6) dan mockup (User Interface) dari Sesi 2. Bila tertinggal: [`BRD acuan`](../session-1/hands-on-3/sources/brd-v1-1-checkpoint.md).
- Referensi tambahan (opsional): [`Reference BRD Role Management`](../session-2/reference-brd-role-management.md) untuk mengecek perilaku permission dan konfirmasi Submit. BRD utamamu tetap hasil Sesi 1.
- Mockup dan tabel brief UI dari Sesi 2 (screenshot, PDF, atau HTML). Bila tertinggal: minta brief UI dan flow spec acuan ke instruktur.
- Claude Code siap dipakai lewat salah satu jalur: tab **Code** di aplikasi Claude desktop (ikut terpasang bersama aplikasi, tanpa instalasi tambahan, butuh paket Pro atau lebih tinggi), atau terminal (`claude --version` menampilkan versi, dipasang di Sesi 2).
- Akun Claude Pro, akun Notion milikmu sendiri, dan Project **WebTM Role & User Management** dari Sesi 1 dengan connector Google Docs yang tersambung.
- Browser (Chrome, Edge, atau Safari) untuk membuka prototype.

Tidak ada Skill baru di sesi ini. User story, backlog, brief progres, dan dampak catatan meeting dikerjakan dengan prompt template di berkas langkah.
