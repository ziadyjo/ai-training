# Skema backlog WebTM

| Properti | Tipe di Notion | Nilai |
|---|---|---|
| Story ID | Title | S-01, S-02, dan seterusnya |
| User Story | Text | "Sebagai [peran], saya ingin [tujuan], supaya [manfaat]" |
| Acceptance Criteria | Text | Butir yang bisa dijawab ya atau tidak, satu per baris |
| Requirement ID | Text | RM-xxx dari BRD (RM-001 sampai RM-007 di BRD v1.1) |
| Priority | Select | Must, Should, Could |
| Size | Select | S, M, L |
| Dependency | Text | ID story lain, atau "tidak ada" |
| Status | Select | Backlog, In Progress, Done, Blocked |
| Sprint | Text | Kosong di awal |

Aturan:
- Satu baris satu story. Story dengan Size L sebaiknya dipecah.
- Status awal semua story adalah Backlog.
- Story Must tidak boleh bergantung pada story Could.
- Requirement yang masih TBC tidak menjadi story. Catat di daftar pertanyaan.
